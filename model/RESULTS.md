# 과제 1 조업형태 분류 — 피처 통합 · 랭킹 · 모델 실험 결과 (2026-10-25)

> 평가: 선박 단위 **macro-F1**, `rfid_id` 기준 StratifiedGroupKFold(5) OOF. 선박 7,372척
> (연안복합 3,650 / 자망 2,520 / 통발 1,044 / 채낚기 158). 피처 선정·튜닝은 모두 fold 안에서만 수행.
> Pool **A** = 위치 제외(순수 행동, 신규 해역 일반화용) / Pool **B** = 위치 포함.

## 0. 한 줄 요약

|---|---|---|---|
| Pool A (위치 제외) | ~0.43 | 0.383 | **0.523** (앙상블 + 클래스 보정) |
| Pool B (위치 포함) | 0.528 | 0.394 | **0.540** (앙상블) |

- 단일 모델 최고는 **CatBoost**: A 0.497(보정 시 0.519), B 0.531(보정 시 0.535).
- **위치를 빼도 0.52**까지 올라와서, 위치 피처의 기여는 0.10에서 0.02로 줄었습니다. 해역 shortcut 의존도가 크게 낮아졌습니다.
- 가장 약한 클래스는 **통발**(F1 0.28~0.36)이고, 자망↔연안복합 이진 F1은 0.62~0.65에 머뭅니다.

## 1. 피처 통합 (`fe_hourly.py` → `fe_aggregate.py`)
| 단위 | 규모 | 내용 |
|---|---|---|
| L1 시간 | 3,887,065행 × ~100 피처 | 나연 v2 정제(튐 제거·6구간 평활·불가능 이동 제외·10분 속도), 지유 P0/P1, 민성 지터 강건(5-step 속도/방향/회전, 체류점), 진우 스펙트럼, 가설 B·C·D |
| L2 선박-일 | 399,025행 × 104 | 활동량·거리·범위·항차·조업시간대·mv_* 44개·재방문(가설 A)·하루 리듬(가설 E) |
| L3 선박 | 7,372척 × 346 피처 | 출어일 통계(mean/median/std/p90), 조업 시간대 풀링 분위수(민성 C), 어장 반복, 계절(H), bag-of-days(G), 위치 7개 |

원본 코드가 아니라 명세를 보고 다시 구현했기 때문에 숫자가 조금씩 다릅니다. 예를 들어 공용 항구 격자가 나연 명세는 501칸인데 여기서는 875칸입니다(정박 판정 기준 차이). 시간대 상태 비율은 PORT 54%, DRIFT 16%, SEA_STOP 13%, FISH 12%, TRANSIT 6%입니다.

## 2. 피처 선정 방법과 이유 (`rank_features.py`)
| 단계 | 방법 | 이유 |
|---|---|---|
| ① 지표 3종 | **mean\|SHAP\|**(0.4) + **순열 중요도**(0.4, 내부 valid macro-F1 감소) + **MI**(0.2) 순위 평균 | SHAP은 모델 기여를, 순열은 대체 불가능성을, MI는 모델에 무관한 단변량 신호를 봅니다. 한 지표의 편향을 상쇄하려고 섞었습니다. |
| ② Boruta shadow | 모든 피처의 행을 섞은 그림자 피처와 SHAP 비교 | 노이즈 기준선(HANDOFF §5)을 피처마다 자동으로 적용 |
| ③ 중복 제거 | 순위 순서대로 Spearman \|ρ\|≥0.95면 하위 피처 제외 | ratio_fishing↔ratio_stop 같은 쌍 정리 (346 → 약 255) |
| ④ **k 선정** | k ∈ {5…150, 전체} 스윕, **1-SE rule**: 최고점 − 1 표준오차 안에서 가장 작은 k | 통계적으로 구분되지 않으면 더 단순한 모델을 택합니다(과적합·유지비용 감소). |
| 누수 방지 | ①~④ 전부 외부 fold의 train에서만 계산하고, 내부는 3-fold | 피처 선정 누수 방지 (HANDOFF §3.1) |

**결과** (`results/k_sweep.png`, `feature_ranking_{A,B}.csv`)
- **Pool B: k\* = 30.** k=30에서 0.530, 최고(k=150)는 0.533으로 차이가 1 SE 이내입니다.
- **Pool A: k\* = 전체 비중복(~250).** k=60에서 0.447, 전체에서 0.461로, 피처를 줄이면 1 SE 넘게 떨어집니다. 위치를 빼면 행동 신호가 **약한 피처 여러 개에 얇게 퍼져 있다**는 뜻입니다.
- 순위 안정성 주의: 5개 fold에 공통으로 들어간 상위 피처는 3~5개뿐입니다. 그래서 보고용 전체 순위는 `topk_freq`(fold 간 선택 빈도)를 1순위 기준으로 정렬했습니다.

**상위 피처** (가설 피처 비중: A 상위 50개 중 66%, 전체 후보 중 44%)
- A: `fh_pca_elong_q90/q50`(직선 투망 연신율), `longest_streak_mean`, `mv_n_stop_move_switch_median`, `season_m5/m1_share`, `mv_ks_straight_max_m_std`, `revisit_cell_ratio_mean`, `moving_days_per_month`, `area_range_km`, `mv_share_night_mean`
- B: `area_range_km`, `cross_day_revisit`, `mv_n_stop_move_switch_median`, `lat_c`, `longest_streak_std`, `daytype_2_share`, `home_port_km`, `mv_ks_straight_max_m_std`, `n_cells_200m_std`, `lon_c`
- 범주로 보면 하루 리듬(E), 직선 투망·경로형태(B), 재방문·어장 반복(A), 방향·회전(D)이 상위권을 차지했습니다. **진행1 §6의 가설이 피처 단위에서 지지됩니다.**

## 3. 모델 실험 (`train_classifiers.py`, `summarize_results.py`)
`+adj` = 클래스별 확률 가중치를 **다른 fold의 OOF와 정답으로만** 맞춰 해당 fold에 적용한 macro-F1 보정입니다(해당 fold 정답은 쓰지 않음).

| 모델 | A | A +adj | B | B +adj | B 통발 F1 | B 자망↔연안 F1 |
|---|---|---|---|---|---|---|
| M0 LogReg (기준) | 0.383 | 0.443 | 0.394 | 0.445 | 0.30 | 0.59 |
| M1 RandomForest | 0.423 | 0.488 | 0.511 | 0.533 | 0.23 | 0.64 |
| M2 LightGBM + Optuna(nested) | 0.463 | 0.508 | 0.526 | 0.526 | 0.34 | 0.64 |
| M3 CatBoost (SqrtBalanced) | **0.497** | 0.519 | 0.531 | 0.535 | 0.31 | 0.65 |
| M4 TabM (SOTA) | 서버 실행 예정 | | 0.486 | 0.525 | 0.34 | 0.63 |
| M5 가설 2단계 계층 | 0.462 | 0.505 | 0.534 | 0.527 | 0.33 | 0.64 |
| M6 앙상블 (M2+M3+M4+M5) | 0.471 | **0.523** | **0.540** | 0.540 | 0.34 | 0.65 |
| (ablation) LightGBM 기본값 | 0.460 | 0.498 | 0.538 | 0.530 | 0.33 | 0.65 |

fold 간 표준편차는 0.01~0.026입니다. 모델 간 차이가 0.01 안쪽이면 사실상 같은 수준으로 봐야 합니다.

## 4. 해석 (좋은 결과와 안 좋은 결과 모두)
1. **CatBoost가 가장 안정적인 단일 모델**입니다. 클래스 가중을 Balanced에서 SqrtBalanced로 바꾸자 B가 0.456 → 0.531로 올랐습니다. 채낚기(158척)를 과보정한 게 원인이었습니다.
2. **가설 2단계 모델은 효과가 없었습니다.** 같은 1단계 LightGBM 단독(ablation)과 비교하면 A는 +0.002, B는 −0.004입니다. 자망↔연안복합 전문 분류기를 따로 둬도 4클래스 모델이 이미 같은 가설 피처를 쓰고 있어서 더해지는 정보가 없습니다. 결론: **가설은 '피처'로는 유효하고, '구조'로는 이득이 없음.**
3. **Optuna 튜닝 이득은 작거나 음수였습니다**(B 0.526 vs 기본값 0.538). 선박 4.7천 척을 내부 3-fold로 나누면 튜닝 목표 자체가 잡음이 큽니다. 튜닝보다 클래스 가중과 결정 보정 쪽 효과가 큽니다.
4. **TabM(SOTA)은 GBDT보다 낮습니다**(B 0.486). 표본이 7천 척 수준이라 딥러닝 테이블 모델이 GBDT를 넘기 어렵습니다. 다만 보정 후 0.525까지 올라오고 앙상블 다양성에는 기여합니다.
5. **클래스 보정(+adj)은 Pool A에서 효과가 큽니다**(+0.04~0.06). 위치가 빠지면 모델 확률이 다수 클래스 쪽으로 치우치고, 보정이 이를 바로잡습니다. B에서는 거의 0입니다.
6. **오분류는 대부분 '연안복합'으로 빨려 들어갑니다**(`cm_A_best.png`: 자망의 51%, 통발의 49%가 연안복합으로 예측). 연안복합은 여러 어구가 섞인 다봉 분포 클래스(진행1 §6-1)여서 다른 업종과의 경계가 넓게 겹치는 것으로 보입니다.
7. **통발이 병목**입니다(F1 0.23~0.36). 다음 개선은 통발 vs 자망·연안복합에 집중해야 합니다(예: 어구 투하 지점 격자 반복성, 정지 지점 간 간격).

## 4-1. MIL 실험 (`mil.py`, 시드 1개, CPU)
선박 1척을 출어일(L2 피처 93~101개) 묶음으로 보고, gated attention이 정보가 있는 날에 가중치를 주게 했습니다. 동기는 "선박 평균이 업종 신호를 희석시킨다"는 가설의 검증입니다.

| | A | A +adj | B | B +adj |
|---|---|---|---|---|
| MIL 단독 | 0.489 | 0.479 | 0.511 | 0.524 |
| 기존 앙상블 | 0.471 | **0.523** | 0.540 | 0.540 |
| 앙상블 + MIL | 0.515 | 0.505 | 0.537 | 0.539 |
| CatBoost + MIL | 0.503 | 0.501 | 0.528 | **0.545** |

- **천장을 올리지는 못했습니다.** MIL 단독은 GBDT와 같은 수준이고, 결합해도 최고점 차이(B 0.545 vs 0.540)가 fold 표준편차(±0.015) 안입니다.
- **attention은 의도대로 작동합니다.** 이동일에는 균등 대비 1.24배, 비이동일에는 0.08배를 줍니다. attention 상위 3일 가운데 95%가 이동일이고(전체 이동일 비율은 79%), 그날들은 표류 비중 0.20(전체 0.11), 조업속도 비중 0.07(전체 0)로 조업 활동이 많은 날입니다.
- 정리하면, 정보가 있는 날을 골라서 봐도 점수가 그대로입니다. 따라서 **희석은 주된 병목이 아니고**, 한계는 하루 단위 피처의 정보량 또는 라벨(연안복합 허가 혼합) 쪽이라는 근거가 됩니다. 단, 이 MIL도 '하루 요약 피처'를 입력으로 쓰므로, 원시 점 시퀀스나 항적 이미지를 학습하는 방법은 아직 검증하지 않았습니다.
- **기간 길이에 강건합니다.** 배마다 7일만 줘도 A 0.476, B 0.497로 전체 기간 대비 −0.013 수준입니다. Test A가 짧은 기간으로 주어질 경우의 대비책이 됩니다.

## 5. 한계와 주의
- bag-of-days KMeans(가설 G)는 라벨 없이 전체 선박으로 적합했습니다. 라벨 누수는 없지만 transductive하므로, Test A에서는 Test 선박을 포함해 다시 적합하거나 train 적합 모델로 predict해야 합니다.
- 랭킹용 LightGBM은 빠른 설정입니다(200 trees, max_bin 63). k\*는 이 모델 기준이라 다른 모델에는 최적이 아닐 수 있습니다.
- `+adj` 보정은 fold 정답을 쓰지 않지만, 같은 데이터 분포 안에서의 보정입니다. Test A의 클래스 비율이 다르면 효과가 줄 수 있습니다.
- 시간 단위(L1) 예측과 시간행 단위 제출 포맷은 아직 구현하지 않았습니다. 지금은 선박 단위입니다.
